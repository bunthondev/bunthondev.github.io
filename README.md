# bunthondev.github.io

Home page for my open-source macOS utility apps: https://bunthondev.github.io/

## Apps

- **[RunDock](https://bunthondev.github.io/RunDock/)** ([repo](https://github.com/bunthondev/RunDock)) — Rust + Tauri desktop app, menu bar switcher, and CLI shim manager for Node.js, Python, PHP, Go, Bun, Deno, Java, package managers, and local services (PostgreSQL, Caddy, Mailpit, Nginx).
- **[DeepClean](https://bunthondev.github.io/deep-clean/)** ([repo](https://github.com/bunthondev/deep-clean)) — Small native SwiftUI Mac app for inspecting developer caches, `node_modules`, and build folders, explaining what each one is before moving anything to Trash.
